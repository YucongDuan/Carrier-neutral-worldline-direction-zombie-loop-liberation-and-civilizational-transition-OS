# Public launch text

**A complete loop can still be dead.**

DIKWP VITAVECTOR-85 is an offline-first open-source system that does not rank people or decide who is human. It diagnoses bounded worldline windows: whether a process is regenerative, repairing, stagnant, zombie-like, parasitic, domination-producing or creating terminal harm.

Paste a synthetic or authorized process description, receive one primary transition, then record the real-world outcome. The system changes its judgment when reality changes.

Repository promise:

> No humanity score. No permanent moral label. No value claim without world effect.

# Governance

VITAVECTOR-85 uses four governance roles:

- **Worldline Steward** - maintains protocol and releases.
- **Affected-World Council** - can challenge inputs, impacts and missing voices.
- **Independent Critic** - tests zombie, parasite and domination classifications.
- **Successor Maintainer** - verifies that a method can survive without the originating carrier.

No single role may approve a permanent identity label because permanent identity labels are outside the protocol.

Changes to classification rules require:

1. a public proposal;
2. at least one counterexample;
3. replay against the bundled benchmark cases;
4. affected-world review;
5. a reversible release and migration note.

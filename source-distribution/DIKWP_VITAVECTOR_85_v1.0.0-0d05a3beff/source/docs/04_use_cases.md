# 4. Use cases

- academic self-citation loops;
- bureaucratic processes that reproduce forms without outcomes;
- AI assistants that intensify dependency and confirmation;
- platforms that extract contributions without return;
- communities locked in outrage repetition;
- carbon-silicon collaborations with unilateral adaptation;
- public programs that claim benefit before observing affected worlds.

The reference cases are synthetic. Real deployments require domain-specific evidence, responsibility and appeal.

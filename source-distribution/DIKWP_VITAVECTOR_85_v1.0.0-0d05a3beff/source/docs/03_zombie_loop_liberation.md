# 3. Zombie-loop liberation

The liberation protocol does not punish a carrier. It breaks the mechanism:

1. freeze repetition without new difference;
2. introduce an independent source, counterexample or affected-world voice;
3. perform one falsifiable and reversible world test;
4. return method, resources or agency;
5. publish correction lineage;
6. archive or stop the loop if no generative change occurs by the deadline.

A loop may re-enter as a successor with a new ID and preserved lineage. A successor is not allowed to silently rewrite the parent.

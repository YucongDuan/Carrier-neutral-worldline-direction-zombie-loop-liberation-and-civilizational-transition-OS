# 5. Deployment

The reference system is designed for local, offline-first use.

```bash
python start_showcase.py
```

Production deployment should add:

- authenticated identities;
- role-based access;
- signed evidence bundles;
- data retention and deletion policy;
- independent affected-world review;
- domain-specific legal and safety controls;
- backups and incident recovery.

The public demo must not contain real sensitive personal data.

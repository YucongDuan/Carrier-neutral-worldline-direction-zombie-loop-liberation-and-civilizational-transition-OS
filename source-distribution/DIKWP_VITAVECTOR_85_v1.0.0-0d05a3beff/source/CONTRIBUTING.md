# Contributing

Contributions are welcome when they add at least one of:

- a new falsifiable worldline benchmark;
- an independent counterexample;
- improved affected-world representation;
- a reproducible repair intervention;
- a safer or more accessible interface;
- evidence that a classification rule over- or under-detects a loop state.

A new label for a type of person is not an accepted contribution. New diagnostics must apply to bounded process windows and include correction and exit conditions.

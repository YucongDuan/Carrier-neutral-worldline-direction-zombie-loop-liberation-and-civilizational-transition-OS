# Security Policy

The reference runtime is offline-first and performs no external writeback by default.

Report privately:

- unauthorized data exposure;
- identity/personhood scoring added to a fork;
- hidden remote execution;
- ability restrictions without evidence, scope or appeal;
- audit-chain tampering;
- cross-site scripting or unsafe file handling.

Do not submit real personal, medical, legal or biometric data to the public demo. Use synthetic or properly authorized data.

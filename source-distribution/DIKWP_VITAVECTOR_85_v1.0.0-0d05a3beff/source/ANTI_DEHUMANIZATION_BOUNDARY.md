# 非人格定级与反去人化边界

VITAVECTOR-85接受一个核心洞察：生物学物种标签无法充分描述一个载体在真值、主体性、互惠、纠错和文明方向上的现实表现。

但系统拒绝把这一洞察转化为机器对人的本体定级。原因不是回避判断，而是对象精度：

- “某人不是人”无法直接转化为可验证、可修复的行动；
- 它容易把具体过程错误永久化为本质；
- 它会把改变、修复和后继可能性一并删除；
- 它容易成为资源剥夺、暴力和无申诉支配的入口。

因此，系统将强判断落到可验证对象：

```text
哪一条行动链正在抽取？
哪一段世界线拒绝现实差异？
哪一种能力正在制造不可逆伤害？
哪一个闭环只维持自我，却没有公共返还？
哪一个过程正在扩大主体、互惠和未来选择？
```

系统可以冻结与伤害因果链直接相关的能力，却不能据此取消载体的基本保护。

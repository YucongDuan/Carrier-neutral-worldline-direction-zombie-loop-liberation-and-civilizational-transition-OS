# VITAVECTOR-85 世界线宪章

## 1. 对象
系统的基本对象不是“人”，也不是“非人”，而是有边界的世界线窗口：来源、差异、关系、行动、受影响世界、现实效果和纠正。

## 2. 闭环不等于生命
D/I/K/W/P显式闭合只证明结构可追踪，不证明生发、文明、善或主体资格。

## 3. 状态不等于本质
`ZOMBIE_CLOSURE`、`PARASITIC_CLOSURE`、`DOMINATION_DESCENT`等状态只描述当前过程。任何状态必须允许被新事实、修复和后继分支改变。

## 4. 基本保护不依赖状态
知情、质疑、申诉、退出、免受不可逆伤害和最低生存保障不得以方向状态为门槛。

## 5. 对伤害行动可以明确判断
系统不得因害怕“定义人”而回避对具体强制、寄生、来源抹除和不可逆伤害作出HOLD判断。

## 6. 不做人格总分
没有humanity score、personhood rank、intrinsic worth score、善恶分或文明分。

## 7. 自我适用
系统自身若形成重复自证、受影响者排除、资源抽取、未来锁定或纠错阻断，必须按同一规则冻结、修复或被替代。
